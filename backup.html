The Index

Translate a thought into a permanent coordinate within the infinite library.

The Index mathematically hashes your query into a deterministic address. The exact same query will always reveal the exact same volume, chapter, and page across all time.

Architecture of the Infinite

Unlike standard databases, this library stores nothing. The text you read is hallucinated into existence in real-time by a Large Language Model (or a procedural algorithm) running entirely within your browser. By tying the generation to strict deterministic constraints, the hallucination becomes permanent.

The Mechanism of Hashing

Every coordinate (Volume, Chapter, Page) undergoes a bitwise collision-resistant hash to produce a unique 32-bit integer seed. This gives ~999 billion uniquely seeded pages. Every address is valid, and no page is repeated unless you return to the exact same coordinate.

Local WebGPU Inference

When "Intelligence" is awakened, a compressed Large Language Model (SmolLM2) is downloaded into your browser's IndexedDB. Via WebGPU, matrix multiplications run purely on your local hardware. No text leaves your device, no API keys are used, no server cost.

Zero-Temperature Determinism

The LLM receives the deterministic seed from your address and generates at Temperature=0.001. Because both the seed and sampling temperature are fixed, the neural network always produces the exact same token sequence for a given address.

The Procedural Fallback

Without WebGPU, the Library degrades to a procedural Pseudo-LLM using XORShift32 seeded RNG to construct Borges-esque literary prose from a grammar dictionary. It retains the exact same mathematical permanence as the AI engine.
