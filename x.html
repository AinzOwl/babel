The Index

Translate a thought into a permanent coordinate within the infinite library.

The Index mathematically hashes your query into a deterministic address. The exact same query will always reveal the exact same volume, chapter, and page across all time, acting as a permanent pointer to generated meaning.

Architecture of the Infinite

Unlike standard databases, this library stores nothing. The text you read is hallucinated into existence in real-time by a Large Language Model (or a procedural algorithm) running entirely within your browser. By tying the generation strict deterministic constraints, the hallucination becomes permanent.

The Mechanism of Hashing

Every coordinate (Volume, Chapter, Page) undergoes a bitwise hashing collision-resistant algorithm to produce a unique 32-bit integer seed. This means the address space gives roughly 999 billion uniquely seeded pages. Every address is valid, and no page is ever repeated unless you return to the exact same address.

Local WebGPU Inference

When "Intelligence" is awakened, a compressed 1.7 Billion parameter Large Language Model (SmolLM2) is downloaded into your browser's IndexedDB. By utilizing WebGPU, the matrix multiplications required for AI generation run purely on your local hardware. No text leaves your device, no API keys are used, and there is no server-side cost.

Zero-Temperature Determinism

To guarantee permanence, the LLM receives the deterministic seed generated from your address, and generates text at exactly `Temperature=0.001`. Because both the seed and the sampling temperature are fixed, the mathematical output of the neural network is completely constrained. It will always dream the exact same sequence of tokens for that given address.

The Procedural Fallback

If your browser lacks WebGPU support (or you choose not to download the model weights), the Library gracefully degrades to a procedural "Pseudo-LLM". It uses an implementation of the XORShift32 seeded random number generator to construct Borges-esque literary prose from a localized grammar dictionary. It retains the exact same mathematical permanence as the AI engine.
